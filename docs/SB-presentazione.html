Second Brain · SB

La memoria viva di ogni progetto

Una mappa astratta ma precisa di tutti i file, i collegamenti, le aree e le meccaniche di un progetto — sempre aggiornata, interrogabile, e a costo di token quasi nullo.

Non è "un altro posto dove immagazzinare roba". È il quadro canonico che l'AI consulta per avere sempre chiara la situazione: mai più pezzi dimenticati, mai più "ne avevamo parlato tre chat fa", mai più file non aggiornati.

Il problema

Oggi l'AI ricostruisce il contesto rileggendo i file. Ogni volta.

Senza una mappa viva del progetto, a ogni sessione (o a ogni dubbio) l'assistente deve cercare e rileggere i documenti per capire dov'eravamo: il file sorgente-di-verità, le note, i rapporti, il codice. È lento, è incompleto — e brucia token a ripetizione.

Il documento sorgente-di-verità di un progetto maturo può pesare ~180.000 token da rileggere per intero. Aggiungi memorie e scansioni mirate del codice e una ricostruzione "a freddo" del contesto costa facilmente decine o centinaia di migliaia di token — che si ripetono sessione dopo sessione e crescono col progetto.

La soluzione

Un cervello per progetto, sempre fresco, interrogabile a query mirate.

SB costruisce una volta il grafo del progetto e lo mantiene aggiornato a ogni passo (in automatico, fuori dal modello). L'AI non rilegge tutto: interroga e riceve risposte compatte. L'umano apre un'UI 3D navigabile e vede l'intero progetto a colpo d'occhio.

Sempre aggiornato

Hook + diff incrementale: il grafo è sempre allineato ai file. Un gate anti-deriva blocca "a posto" se resta qualcosa di stantio o orfano.

Read-only & sicuro

Indicizza, non tocca mai i file del progetto. Applicabile anche a progetti vivi senza alcun rischio.

Per-progetto

Ogni progetto ha il suo cervello dedicato, caricato all'apertura. Il titolo del progetto è in cima all'UI.

UI 3D navigabile

Nodi colorati per tipologia, archi colorati per tipo di legame, descrizioni chiare. Aree e collegamenti a colpo d'occhio.

Costo-token quasi nullo

Mai il grafo intero nel contesto. Bootstrap compatto + query mirate. L'UI ricca è nel browser: zero token per l'AI.

$0 e locale

Nessun cloud, nessuna API a pagamento, nessun lock-in. I file restano la verità; il grafo è derivato e rigenerabile.

SB non sostituisce: integra. Riusa un grafo-codice AST esistente per il livello-codice e prende i pattern migliori (file-come-verità, indice locale, MCP), aggiungendo i pezzi che mancano: riferimenti documentali nella prosa, nodi di decisione/sessione, anti-deriva e UI 3D.

Come funziona

Indicizza (una volta)

Scansiona il progetto e costruisce il grafo: file tipizzati + entità di codice + riferimenti documentali + decisioni e aree.

Resta fresco (a ogni passo)

Hook + diff incrementale rigenerano solo ciò che cambia, fuori dal modello: costo-token zero.

L'AI interroga

Bootstrap compatto all'avvio, poi query mirate via MCP: niente rilettura di interi file, niente grafo nel contesto.

L'umano vede

UI 3D navigabile: titolo del progetto in testa, nodi e archi colorati per tipo, descrizioni, aree a colpo d'occhio.
